Config is Figma's annual global design conference
Bringing together the design community to celebrate creativity, collaboration, and the future of design.
This conference provides HCHB the opportunity for the following:
  1. Assess new Figma products and capabilities
  2. Identify emerging UX trends and innovations
  3. Discover scalable UX methodologies
  4. Optimize UX-to-Product delivery workflows
  5. Accelerate time-to-market through process improvements
  6. Benchmark industry best practices and future-state design paradigms

New methodologies
  • Design and code as a single workflow.
  • AI as a collaborative team member, providing variations.
  • Prompt to tool development.
  • Rich prototyping before development.
  • The canvas is the product workspace.
  • Design Systems as living products.
Top opportunities for HCHB
  • Automating UX design and lead reviews.
  • Systems integration with MD files to clean up code outcomes.
  • Agent integration will allow rapid iteration cycles.
  • Pushing real code changes from designers back to Git for code review.
  • Plugin tool development for menial tasks will reduce time.
  • Rapid AI prototyping will allow for continuous experiments and validation.

Citrix Elimination
Building the foundation for a modern user experience
UX work led by Wes Pallister with assistance in testing from Lindsay Garlock
Driving cross-functional alignment
Championing the UX vision
Led communication and alignment efforts across product, engineering, and leadership teams to advocate for shared standards, patterns, and design practices. By building awareness and adoption of UX assets across the program, this work helped position UX as a strategic contributor to the Citrix Elimination initiative and strengthened collaboration across disciplines.
A big thank you to all involved in gaining alignment
Including but not limited to: Tamara Khan, David Pittman, Jason Pagel, Jen Ball, Sandy Griffiths, Nathan Biefeld, Daniel James, Priti Aggarwal, Christian McKennon, Natalie Fleet, and many more.
Mapping the legacy experience
Turning complexity into clarity
Conducted a comprehensive analysis of the legacy Citrix application and created an application map documenting screens, workflows, dependencies, and system relationships. This established a shared understanding across teams, helping identify modernization priorities and support better planning decisions.
Agency management flow chart
Designing reusable screen templates
Bringing the future state to life
Designed and prototyped modernized screens while creating a library of reusable templates, design patterns, and component-based references for implementation.
Defining modern UX patterns
Creating consistency at scale
Developed a UX patterns library that evaluates legacy interaction models and defines modern replacements aligned with current UX standards and the design system.
UX patterns from WinForms to Blazor
Validating through user research
Validating design decisions with internal & customer users
Conducted usability testing with 12 internal users and 5 customer users. Overall, users were able to complete core workflows and found the web-based application more modern and easier to use, while also highlighting areas that need stronger discoverability.

Intake Central
Enhancing Medicare eligibility review
UX work led by Tessa Veto
Simplifying access to coverage information
  Designed a Medicare eligibility flyout experience that surfaces coverage details directly within the intake workflow using a vendor-agnostic, payer-aware UI model. The solution supports multiple coverage segments, partial and error states, automatic refresh behavior, and future vendor extensibility while helping intake coordinators review critical details without workflow disruption.
