Modernizing payer information
Delivering payer-specific clarity
Redesigned the Patient Info payer section to support Commercial, Medicaid, Medicare, and Medicare Advantage payer types with tailored coverage and authorization information. The enhanced experience surfaces more relevant payer details based on coverage type, helping clinicians access information more efficiently, reducing confusion, and supporting more accurate documentation workflows.

Supporting proactive clinical review
Improving visibility into Potentially Avoidable Events (PAE)
  Designed notification workflows for Potentially Avoidable Event (PAE) triggers within Care+ Physical Assessments. Contextual alerts help clinicians identify situations that may require additional review, increasing awareness of PAE-related conditions while supporting compliance initiatives and more consistent clinical documentation practices.

Increasing resilience in AI-assisted documentation
AI Scribe error handling for scoring engine failures
  Designed non-blocking error handling for AI Scribe scoring engine failures within Physical Assessment workflows. When scoring services are unavailable, clinicians can continue documenting without interruption while receiving clear guidance and status messaging, improving workflow continuity and confidence in AI-assisted experiences.

Keeping clinicians productive during service interruptions
Designed the end-to-end UX workflow for generating AI-powered post-visit summaries through Steno integration. Supports clinician efficiency by reducing documentation effort through AI-generated summaries.
 
User clicks "Write visit summary" from the Visit review section within the visit.   User can freeform their own notes, however in this scenario the user clicks "AI Generate".
 
 
Skeleton loading appears after selecting "AI Generate" to give a visual cue of the action. The button also changes to "AI generating" with the loading spinner replacing the AI sparkles icon.   Upon loading the text appears based on the actions taken in the visit.

Creating a more reliable path to submission

Care+
Simplifying visit billing workflows
UX work led by Ezequiel "Zeque" Dominguez
Improving claim-code selection
Making billing decisions easier and more accurate
  Led the UX design and workflow definition for Visit Claim Code Selection in Care+, enabling Home Health clinicians to review, retain, edit, or override visit-level claim codes directly within the end-of-visit workflow. The experience simplifies complex billing interactions by presenting only valid claim-code options, clearly communicating the default billing intent, and reducing unnecessary decision-making. By improving visibility and guidance within the workflow, the solution helps clinicians make more accurate billing-related decisions, reduces downstream correction effort, and establishes a scalable foundation for future billing enhancements.
Figma for "Claim Code in Care+"
Streamlining initiation visit documentation
Improving interventions and goals documentation - Guiding clinicians through required pathways
Designed the initiation visit interventions and goals workflow in Care+, enabling clinicians to document required care activities through First Visit Pathways based on service line, discipline, and visit type. The experience gives clinicians clearer guidance for completing required interventions, documenting goal outcomes, adding needed detail, and handling exceptions within the correct pathway context. By reducing ambiguity and enforcing validation before save, the workflow supports more complete documentation, improves compliance alignment, and creates a scalable foundation for future pathway-driven Care+ experiences.
Figma for "Interventions and goals in Care+"
Improving allergy management
Safer and more complete patient allergy documentation
  Designed the milestone-one allergy management workflow in Care+, enabling clinicians to view, search, add, edit, and manage allergies and NKA directly within the initiation visit experience while maintaining synchronization with R2. The experience provides clinicians with a clear and reliable way to document allergy information without leaving their workflow, including support for non-codified and unlisted allergies, required reviews, validation, and conflict prevention. By improving documentation clarity and maintaining accurate synchronization across systems, the solution supports patient safety, reduces reliance on legacy workflows, and establishes a scalable foundation for future allergy management enhancements.
Figma for "Allergies management in Care+"
Simplifying visit acceptance
Giving clinicians a clearer path to managing scheduled work
Designed the first-milestone Accept Visit workflow within the Care+ CSA/Map experience, enabling clinicians to confirm ownership of scheduled visits directly from map views, visit cards, and action menus. The experience provides immediate feedback when visits are accepted, improves visibility into visit ownership, and reduces uncertainty within daily scheduling workflows. By bringing visit acceptance directly into Care+, the solution reduces scheduling friction while establishing a foundational framework for future scheduling-management capabilities within the platform.

Web Scheduling
Advancing clinical and scheduling workflows
UX work led by Ezequiel "Zeque" Dominguez
Bringing Find Shifts into the web experience
Making staffing opportunities easier to manage
Designed the Find Shifts experience within Web Scheduling, bringing key Scheduling Console functionality into the modern web workflow. The solution includes streamlined actions for eligible visits, dedicated shift-management queues, and integration with existing filtering, selection, and authorization patterns. By centralizing shift-management activities within Web Scheduling, the experience reduces context switching, improves visibility into open and accepted shifts, and provides schedulers with a more efficient and consistent workflow. The work also closes a key feature gap with legacy tools while establishing a foundation for future scheduling and staffing enhancements.
Figma for "send visit to Find Shifts"
Helping schedulers find information faster
Making scheduling data easier to access
Designed a queue-level search experience for Web Scheduling that enables users to quickly locate visits by patient, worker, or service code directly within their existing workflow. The solution supports cross-queue search, queue-aware results, filter-aware behavior, and streamlined navigation to the appropriate scheduling context. By reducing the need to manually scan large queues, the experience helps schedulers find relevant information more quickly and efficiently. The enhancement improves usability, reduces operational friction, and creates a more scalable approach to managing high volumes of scheduling data while maintaining alignment with existing visibility and compliance requirements.

Intake Central
Improving visibility and workflow efficiency
UX work led by Tessa Veto
Giving users more control over their workspace
Creating a more personalized dashboard
  Designed a customizable Referrals Dashboard experience that allows users to choose and reorder visible columns from a curated set of options while preserving required fields and automatically saving individual layout and sorting preferences. The enhancement gives users a dashboard tailored to their workflow, reducing the need for repeated setup and making referral information easier to scan and manage. By establishing standardized personalization, accessibility, and responsive design patterns, the work improves usability today while creating a scalable foundation for future dashboard customization capabilities.
View Figma for personalized dashboard
Improving referral workload visibility
Making work easier to prioritize
Designed an enhancement to the Referrals Dashboard that replaces a simple task indicator with a Task Count column, giving users immediate visibility into the number of outstanding tasks associated with each referral. This improvement helps users assess workload more effectively, prioritize referrals faster, and reduce unnecessary investigation. By leveraging existing dashboard data and established UI patterns, the solution improves usability while minimizing implementation effort and risk.
View Figma for workload visibility
Streamlining referral management
Reducing effort through quick views
Designed a Quick Views experience for the Referrals Dashboard that enables users to switch between common referral states-including All Referrals, New Referrals, In Progress, and Complete-without manually rebuilding filters. The experience simplifies navigation between common workflows, improves consistency through server-defined view logic, and establishes a scalable framework for future dashboard enhancements. By reducing repetitive filtering and maintaining predictable behavior, users can move between tasks more efficiently while maintaining visibility into their work.
