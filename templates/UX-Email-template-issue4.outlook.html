Creating a UX foundation for AI-driven development
Embedding UX standards into delivery
This work extends UX governance beyond traditional documentation by embedding established UX standards, information architecture patterns, design-system rules, and approved product decisions directly into AI-assisted software delivery. The skills framework provides teams with clear, reusable constraints for interface structure and implementation, including component placement, interaction behavior, navigation patterns, color and design tokens, and other established HCHB conventions.
Improving consistency and reducing rework
Together, this approach gives teams a more consistent and informed starting point while reducing interpretation, unnecessary rework, and downstream UX and QA review effort. AI-generated output will still require professional judgment and validation, but embedding governance into the workflow creates a scalable way to improve consistency across modernization initiatives, accelerate delivery, and maintain stronger alignment with HCHB design standards across teams.

Usability research validates the web migration UX
UX work Led by Lindsay Garlock
Testing the migration with internal teams and customers
Conducted two rounds of usability testing for the Backoffice web migration prototype supporting the Citrix elimination initiative. The research included an unmoderated Maze study with 18 internal participants and moderated think-aloud sessions with external billing and revenue cycle customers, validating key workflows while establishing a repeatable research model for future modernization efforts.
Validating the experience before development
The research confirmed strong usability across core workflows, with a 94.4% task success rate for the Room & Board workflow and all external participants completing primary tasks without facilitator assistance. The studies also identified three high-impact usability improvements—including a critical "open in new window" icon issue—allowing the team to address potential adoption challenges before implementation.
Reducing delivery risk through evidence-based design
Behavioral insights from both studies replaced assumptions with measurable user feedback, enabling more confident design decisions while reducing the risk of costly post-launch rework. The program also strengthened customer collaboration, improved stakeholder alignment around the migration strategy, and established a scalable usability validation process that can be applied across future modernization initiatives.

Care+
Unified medication workspace simplifies clinical workflows
UX work led by Ezequiel “Zeque” Dominguez
One workspace for the complete meds journey
Designed the Medication Workspace for Care+, bringing medication review, maintenance, validation, patient education, safety checks, and attestation into a single patient-centered experience. The solution establishes a longitudinal medication profile while integrating with FDB, Orders, R2, and the Visit Framework to create a unified foundation for medication management.
Reducing navigation while improving accuracy
By consolidating fragmented medication workflows into one workspace, clinicians can complete medication-related tasks more efficiently and with greater consistency. The design is expected to reduce clinician navigation, improve medication documentation consistency, and reduce documentation errors through standardized workflows and integrated safety checks.
Building the foundation for future medication innovation
Beyond improving today's clinical experience, the patient-level medication model creates a scalable platform for future interoperability and AI-assisted capabilities. Standardized documentation, stronger validation, and enterprise integrations establish a foundation that supports safer care, greater compliance, and continued innovation across Care+.

PointCare + Steno
AI-powered pre-visit summaries bring clinical context
UX work led by Lonnie Smith
Embedding AI insights into the existing clinician workflow
Designed the end-to-end experience for integrating Steno's AI-powered Pre-Visit Summary into PointCare, enhancing the existing Client Snapshot with clinically relevant patient summaries. The solution leverages established PointCare workflows and UI patterns while defining summary generation, source resolution, visit-type logic, loading states, and error handling to minimize implementation complexity.
Helping clinicians prepare before every visit
The integrated experience provides clinicians with AI-generated patient context at the start of each visit, reducing the need for manual chart review while preserving the familiar Client Snapshot workflow. By surfacing key information where clinicians already work, the design improves preparedness and supports faster, more informed patient encounters.
Establishing a foundation for AI-assisted care
Building on existing PointCare experiences creates a scalable framework for future AI-powered clinical summaries while accelerating adoption through a familiar interface. The approach reduces development effort, maintains workflow consistency, and positions Care+ for continued innovation in AI-assisted clinical decision support.

Intake Central
Self-Service referral screening puts rule management in administrators' hands
UX work led by Tessa Veto
A Foundation for configurable referral screening
The newest addition to the Admin Console experience is Business rules for managing Intake Central's Phase 1 referral screening rules. Agencies will be able to configure screening behavior themselves while establishing role-based management for agency-wide and branch-specific configurations. The initial release includes four configurable rules: Service area, Preferred partners, Branch capacity, and Payer acceptance.
Faster changes without code deployments
The new experience allows Intake System Administrators and Branch Managers to manage referral screening through a governed, self-service interface. By eliminating routine code changes for common rule updates, the solution is expected to reduce engineering involvement, accelerate screening updates, and improve consistency across agencies through standardized rule definitions and permissions.
Building the foundation for intelligent intake
Clear separation between agency-wide and branch-level settings, validation, audit metadata, and reusable Admin Console patterns will reduce configuration risk while giving agencies greater control over referral processing. The MVP creates a scalable framework that can evolve into richer policy-based rule management, supporting faster operational changes, improved governance, and more predictable intake decisions as Intake Central continues to mature.
Business rules overview
Intelligent automation for branch capacity management
Configurable capacity rules for every branch
The new branch capacity management experience for Intake Central's Admin Console gives administrators a structured way to configure referral routing by branch and discipline. The experience includes configurable admission thresholds, reviewer workflows, notifications, validation, and draft/publish controls, all built using established Admin Console patterns to accelerate implementation and reduce configuration errors.
Smarter referral decisions with automated routing
The solution automatically evaluates branch capacity to determine whether referrals should be accepted, escalated, or declined based on administrator defined rules. By automating routine decisions while preserving reviewer oversight for exceptions, the design is expected to reduce manual referral triage, improve referral turnaround time, and significantly reduce unnecessary escalations.
Strengthening governance while protecting clinician capacity
Discipline specific admission limits help prevent over capacity admissions while creating more consistent, auditable intake decisions across branches. Standardized validation, clear configuration summaries, and reusable Admin Console patterns improve administrator confidence, reduce operational risk, and establish a scalable foundation for future Intake Central enhancements.
