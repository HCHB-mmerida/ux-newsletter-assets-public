UX Unity initiative
Centralized theming foundation
UX established a centralized design system theming foundation, in Fluent, that governs visual standards across products through tokens for fonts, color, and effects. This improves consistency, reduces design debt, and enables scalable governance.
Cross-Product visual alignment
By applying a unified look and feel, UX is creating consistent experiences in Care+, PointCare, and Web scheduling, and Citrix elimination efforts, strengthening recognition and usability across the ecosystem.
Execution acceleration
We onboarded Senior UX Developer Enrique Paz to complete missing components and apply the Unity theme across the library, ensuring roadmap delivery while improving design quality and overall product perception. This ongoing project has a 6-month timeline to achieve the UX team will have updates shared as work is resolved.
Component standardization
Reusable Unity component patterns were introduced to improve reliability, reduce rework, and ensure roadmap goals and maintainability as products evolve.
Modernization enablement
Unity provides the visual and structural foundation required to support modernization across next-generation applications. This includes a host of newly developed components added to the Fluent library. Having these assets in our library will help us scale our AI capabilities.
Adoption strategy
UX is partnering with development on an adoption strategy to guide implementation and promote long-term consistency and scalability across teams that does not interfere with our current roadmap.
Scaling UX Through AI and Automation
 
UX worked on several AI initiatives to speed up and improve outcomes.
AI-Ready Design System frameworks
Codified experience standards
We embedded design system guidance into an AI-consumable markdown framework to standardize outputs during AI-assisted builds, improving consistency and reducing UX operational overhead with Unity work only.

Key principles, including information architecture, navigation, usability, accessibility (WCAG 2.2 AA), and some localization items, have been formalized to ensure alignment across product, design, and engineering.
Operational efficiency gains
These frameworks reduce manual rework and improve the quality of outputs generated during AI-assisted development such as Figma Make builds, or Visual Studio code generation. This is not a replacement for strong UX collaboration or UX review, or test and guide development work, but instead is meant to get AI generated UI consistent across teams.
Internal UX agent
We developed an internal UX agent within Visual Studio to enforce feature-level parity across backlogs, reducing manual effort in Azure DevOps ticket creation for our designers, enabling UX to focus more on design support across teams.
